Principles

Explain pressure

Rest without judgment

No streaks, guilt, or performance language.

Accessibility

  • Target WCAG 2.2 AA; test contrast in final native screens.
  • Use 44×44px or larger touch targets for mobile controls.
  • Support Dynamic Type and screen readers; never use icons alone without labels.
  • Use words and patterns alongside colour for workload states.
  • Respect Reduce Motion; provide a static recovery scene.
  • Provide pause, volume, and a transcript for spoken audio.
  • Confirm before writing to an external calendar.
